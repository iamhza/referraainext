# AI-Native Referra Architecture Plan

## Current State Analysis

### What We Have (Strengths to Build On)
```
✅ Solid Foundation:
- Next.js 14 App Router
- TypeScript throughout
- Dual database (Supabase + MongoDB for PHI)
- Role-based auth system
- Comment/messaging APIs working
- Core referral lifecycle defined
- MVP scope clearly defined

✅ Working Features:
- Authentication (case managers, providers, admin)
- Basic referral CRUD
- Comment system with threading
- Provider/client management
- Role-based dashboards
```

### Current Architecture
```
Frontend: Next.js 14 + TypeScript + Tailwind
Auth: Supabase Auth + RBAC
Data: Supabase (general) + MongoDB (PHI)
API: Next.js API routes
UI: Radix + Shadcn/ui components
```

### Current Workflow (Per MVP)
```
1. Case Manager: Caseload → Create Referral → Provider Selection → Track
2. Provider: Signup/Pay → View Referrals → Accept/Reject → Submit Updates  
3. Admin: Review → Manual Matching → Monitor → Resolve Issues
```

## Implementation Strategy

### Database Evolution
```sql
-- Add AI tables to existing Supabase schema
CREATE TABLE ai_predictions (
  id UUID PRIMARY KEY,
  entity_type TEXT,
  entity_id UUID,
  prediction_type TEXT,
  confidence FLOAT,
  data JSONB,
  created_at TIMESTAMP
);

CREATE TABLE ai_insights (
  id UUID PRIMARY KEY,
  referral_id UUID,
  insight_type TEXT,
  content TEXT,

  created_at TIMESTAMP
);
```

## Risk Mitigation

### Technical Risks
- **AI Hallucination**: Confidence scores + human review
- **Data Privacy**: PHI-compliant AI processing
- **Performance**: Async AI processing + caching
- **Cost**: Smart prompt engineering + result caching

### Business Risks
- **User Adoption**: Gradual introduction + clear benefits
- **Regulatory**: Medicaid compliance maintained
- **Quality**: Human oversight + audit trails
- **Reliability**: Fallback to manual processes

This architecture transforms Referra from a traditional SaaS into an AI-native platform that anticipates needs, automates coordination, and provides intelligent assistance throughout the social services referral lifecycle.
