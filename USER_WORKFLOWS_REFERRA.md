# Referra User Workflows: AI-Native Social Services Coordination

## Overview: The Three User Types

1. **Case Manager** (Primary user - creates referrals, manages caseload)
2. **Provider** (Receives referrals, delivers services, reports progress)  
3. **Admin** (Referra staff - supports matching, resolves issues)

---

## **Case Manager Workflow**

### **Daily Starting Point**
- Case manager from Thomas Allen, Accord, or similar organization
- Managing 20-40 clients on various Medicaid waivers (245D, CADI, BI, DD, EW)
- Needs to coordinate services across multiple providers

### **Core Workflow Steps**

#### **1. Morning Dashboard Review (AI-Enhanced)**
```
Login → AI Dashboard shows:
- "3 clients need immediate attention"
- "Sarah's provider hasn't responded in 48hrs" 
- "John's 6-month service review due tomorrow"
- "2 compliance deadlines this week"
```

#### **2. Client Management**
```
Select Client → AI Context Panel shows:
- Current provider relationships
- Service history and patterns
- Upcoming needs predictions
- Similar client success patterns
```

#### **3. Create New Referral (The Core Flow)**
```
Step 1: Select client needing services
Step 2: AI suggests service type based on client history
Step 3: AI shows 3 best-match providers:
   - Provider A: 95% success rate, 2 openings, responds <2hrs
   - Provider B: 87% success rate, 1 opening, great with autism
   - Provider C: 92% success rate, waitlist, excellent outcomes

Step 4: One-click referral submission with:
   - Auto-populated client context
   - Service specifications
   - Compliance requirements
   - Expected timeline

Step 5: Real-time tracking begins automatically
```

#### **4. Monitor Active Referrals**
```
Referral Dashboard shows:
- Pending provider responses (with AI urgency scoring)
- Active services progress
- Upcoming deadlines
- Recommended actions
```

#### **5. Communication Hub**
```
- Threaded conversations with providers
- AI-suggested responses
- Document sharing
- Progress updates
- Issue escalation
```

#### **6. Compliance & Reporting (Automated)**
```
- AI generates DHS compliance reports
- Tracks service delivery metrics
- Flags missing documentation
- Suggests corrective actions
```

## **Provider Workflow**

### **Starting Point**
- Social services provider (day programs, residential, therapy, etc.)
- Serving clients with disabilities through Medicaid waivers
- Needs efficient way to manage referrals and report progress

### **Core Workflow Steps**

#### **1. Referral Notification & Review**
```
Notification: "New referral from Thomas Allen case manager"
AI Preview shows:
- Client overview with relevant patterns
- "Similar to 3 clients you've served successfully"
- Service requirements breakdown
- Expected timeline and outcomes
```

#### **2. Referral Decision**
```
Accept/Decline with AI assistance:
- AI shows capacity fit
- Predicts success probability
- Highlights potential challenges
- Suggests service modifications
```

#### **3. Service Delivery Documentation**
```
Smart Progress Notes:
Provider types: "John attended today and..."
AI suggests: "...participated in 3 group activities vs 1 last week, 
showing improvement in social engagement per IEP goals"

Auto-compliance checking:
"Documentation covers 8/10 DHS requirements. 
Missing: specific progress toward independence goals"
```

#### **4. Ongoing Communication**
```
- Update case manager on progress
- Request clarifications or modifications
- Report incidents or concerns
- Share achievements and milestones
```

#### **5. Capacity Management**
```
AI helps optimize:
- Current client load
- Available openings
- Waitlist management
- Service scheduling
```
