### **Case Manager Onboarding (30 minutes to first "wow")**

#### **Step 1: Import Existing Caseload (5 minutes)**
```
"Upload your current client list CSV"
→ AI automatically maps to Medicaid waiver types
→ Shows immediate insights: "12 clients may need service updates"
```

#### **Step 2: Connect Current Providers (10 minutes)**  
```
"Who are your go-to providers?"
→ AI suggests based on client types
→ Auto-invites providers to join network
```

#### **Step 3: Create First AI-Assisted Referral (15 minutes)**
```
Select client → AI suggests service type → Shows 3 best providers
→ One-click referral sent
→ "Normally takes 2 hours, you just did it in 2 minutes"
```

#### **Step 1: Capacity Profile Setup (5 minutes)**
```

```

#### **Step 3: Receive First Smart Referral (5 minutes)**
